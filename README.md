# Frontend Mentor - QR Code Component Solution

This is my solution to the QR Code Component challenge on Frontend Mentor. The challenge helped me practice fundamental HTML and CSS concepts, including semantic markup, Flexbox, spacing, typography, and responsive layouts.

## Overview

### The Challenge

Users should be able to:

- View the QR code card centered on the page
- Read the card content clearly on both mobile and desktop devices
- Experience a responsive layout that adapts to different screen sizes

### What I Learned

While building this project, I practiced:

- Structuring content using semantic HTML elements
- Centering content both horizontally and vertically using Flexbox
- Using the CSS box model effectively
- Applying consistent spacing with margin and padding
- Working with typography and color systems from a design specification
- Creating a clean card component layout

One of the key concepts I reinforced was using Flexbox for centering elements within the viewport. I also learned how padding, margins, and typography work together to create balanced layouts that closely match a design mockup.
